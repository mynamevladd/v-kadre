# Слежение за спикером в OBS

Скрипт работает как виртуальный оператор: находит проповедника на 4K-камере и плавно двигает кроп источника в OBS.

- Распознаётся **скелет** человека (модель YOLO-pose): глаза, уши, плечи, бёдра. Кадр строится по **голове и корпусу**, поэтому поднятые руки, жесты и стол, закрывающий ноги, кадр не сбивают. Боком или спиной человек тоже распознаётся.
- Слежение работает **только в сцене «Проповедь»**. В остальных сценах скрипт ничего не трогает.

## Установка (один раз)
1. В OBS: **Инструменты → Настройки сервера WebSocket** → включить. Порт 4455. Если задан пароль, впишите его в `config.json`.
2. Запустить `install.bat` (нужен Python 3.11). Он ставит PyTorch с поддержкой NVIDIA и остальные зависимости. В конце должно быть написано `GPU: True`.

## Настройка OBS
- Создайте сцену **«Проповедь»** и добавьте в неё камеру **одним** источником.
- Впишите названия в `config.json`: `"scene"` — сцена, `"source"` — источник камеры. Писать **точно** как в OBS.
- Для прославления и общего плана добавьте камеру в другие сцены (Добавить → **Существующий источник**). Скрипт меняет только элемент в сцене «Проповедь».
- Советуем **режим студии**: пока сцена «Проповедь» стоит в Preview, скрипт уже находит пастора, и при переключении в эфир кадр сразу правильный.

## Запуск
- `run.bat --preview`: окно для настройки.
  - красная рамка — за кем следим, точки — голова, плечи, бёдра;
  - жёлтая — что уходит в эфир;
  - голубая — зона сцены.
  - Клавиши в окне: `r` выбрать цель заново, `p` пауза (общий план), `q` выход.
- `run.bat`: работа без окна.
- После остановки (Ctrl+C) источник возвращается в исходное положение.

## Параметры `config.json`
| Параметр | Что делает |
|---|---|
| `active_scenes` | в каких сценах работает слежение. `[]` значит всегда |
| `shot` | крупность: `chest` по грудь, `waist` по пояс, `hips` чуть ниже пояса, `knee` по колено |
| `zoom_mode` | `auto` — зум подстраивается под `shot`, `fixed` — постоянный `fixed_zoom` |
| `min_zoom` / `max_zoom` | пределы зума. 2.0 = чистый 1080p из 4K, 3.0 — уже заметно мягче |
| `headroom` | отступ над головой (доля кадра) |
| `deadzone_x` / `deadzone_y` | насколько пастор может сместиться, прежде чем кадр поедет. Больше значит спокойнее |
| `deadzone_zoom` | порог изменения зума (0.2 = 20 %) |
| `smooth_time` | плавность движения в секундах. Больше значит мягче, но с отставанием |
| `zoom_smooth_time` | плавность зума |
| `max_speed` | максимальная скорость панорамы (доля кадра в секунду) |
| `torso_smoothing` | сглаживание размера корпуса (0–1). Больше значит зум стабильнее |
| `kp_conf` | уверенность для точек скелета |
| `lost_timeout` | через сколько секунд без пастора уходить на общий план |
| `wide_on_lost` | уходить ли на общий план, когда пастор потерян |
| `zone` | зона сцены `[x0, y0, x1, y1]` от 0 до 1. Люди вне её игнорируются |
| `detect_fps`, `imgsz`, `detect_width` | нагрузка на видеокарту. Для GTX 1050 Ti оставить 10 / 416 / 640 |
| `model` | `yolo11n-pose.pt` — быстрая, `yolo11s-pose.pt` — точнее, но тяжелее |

## Если что-то не так
- **Дёргается**: увеличьте `deadzone_x` и `smooth_time`.
- **Отстаёт**: уменьшите `smooth_time`, увеличьте `max_speed`.
- **Переключается на других людей**: сузьте `zone`.
- **План не такой крупный, как нужно**: камера далеко, и зум упирается в `max_zoom`. Можно поднять `max_zoom` (картинка станет мягче) или поставить объектив с большим фокусным расстоянием.
- **В OBS пропускаются кадры из-за рендеринга**: уменьшите `detect_fps` до 6–8 или запустите скрипт на другом компьютере. Для этого в `obs.host` укажите IP ноутбука.
