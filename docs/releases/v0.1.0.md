Первая публичная версия «В кадре» — автоматического оператора для OBS Studio.

## Скачать

**`VKadre-windows-x64.zip`** — распакуйте и запустите `VKadre.exe`. Папка `models` должна лежать рядом с exe. Установка не нужна.

Нужны Windows 10/11 (64-бит) и OBS Studio 28 или новее со включённым WebSocket-сервером (Инструменты → Настройки сервера WebSocket).

## Что умеет

- Находит спикера по скелету (YOLO11-pose) и плавно ведёт кадр кропом 4K-камеры.
- Режимы в каждой сцене OBS: «Вести», «Дуэт», «Общий».
- Зона сцены, выбор человека кликом, узнавание спикера по одежде.
- Два плана из одной камеры с монтажной склейкой.
- Плашка с именем по кнопке или клавише N.
- Сторож камеры: чёрный кадр, зависание, пропал сигнал.
- Распознавание на любой видеокарте через DirectML или на процессоре.
- Интерфейс на русском и английском.

## Попробовать без OBS

```
VKadre.exe --demo картинка.jpg
```

Подойдёт любое фото сцены с людьми.

## Если Windows предупреждает

Программа пока не подписана сертификатом, поэтому SmartScreen может показать «Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.
