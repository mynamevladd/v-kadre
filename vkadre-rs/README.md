# «В кадре» на Rust

Та же программа, что и Python-версия в `speakertrack/`, переписанная на Rust: интерфейс на Slint, нейросеть через ONNX Runtime (крейт `ort`, DirectML), свой лёгкий клиент OBS WebSocket v5.

Настройки общие с Python-версией: `%APPDATA%\VKadre\settings.json`. Лог: `%APPDATA%\VKadre\speakertrack.log`.

## Интерфейс

- Пульт: слева монитор камеры и плитки сцен OBS (режим каждой сцены — по клику), справа монитор эфира, показатели и настройки на вкладках.
- Окно «Настройки» (справа вверху): язык, подключение к OBS, автостарт слежения, запуск свёрнутым, горячие клавиши.
- Языки: русский и English, переключаются на лету. Строки интерфейса — ключи по-русски, перевод в `src/i18n.rs`; тест проверяет, что у каждой строки из `ui/app.slint` есть английский.
- Плашка с именем выходит только вручную: кнопка «Плашка», «Показать в эфире» или клавиша N.
- Камера выбирается сама по типу источника OBS (устройство захвата → NDI → медиа → захват окна → остальное), пока человек не выбрал источник руками.
- Отладка: `VKadre.exe --lang en`, `--tab 3`, `--open-settings`.
- Демо без OBS: `VKadre.exe --demo картинка.jpg` — картинка играет роль 4K-камеры (`src/demo.rs`), настройки не сохраняются. Так сняты скриншоты в `docs/screenshots/`.

## Что экономится в фоне

- Сцена не в эфире: потоки спят и ждут события OBS о смене сцены. Ни опроса, ни скриншотов.
- Crop отправляется в OBS, только когда рамка сдвинулась хотя бы на пиксель.
- Режим «Общий»: нейросеть не запускается, 2 кадра/с для превью и сторожа камеры.
- Окно свёрнуто: превью не рисуется.
- На процессоре нейросеть берёт не больше 4 потоков.

Замер в простое (окно открыто, OBS не подключён): Rust — 92 МБ (private 99 МБ), Python — 176 МБ (private 447 МБ). Процессор у обеих ~0 %.

## Сборка

Нужны Rust (stable, MSVC) и Visual Studio Build Tools с C++.

```bat
cargo test              :: тесты
cargo run               :: запуск (отладка)
build.bat               :: релиз в ..\dist-rs\VKadre.exe + модель, с самопроверкой
```

Самопроверка: `VKadre.exe --selftest` (модель и устройство пишутся в лог).

## Структура

| Файл | Что делает |
|---|---|
| `src/framing.rs` | расчёт кадра: поза → окно кропа, мёртвые зоны, сглаживание |
| `src/tracker.rs` | трекер людей между кадрами |
| `src/detector.rs` | ONNX Runtime: letterbox, разбор выхода YOLO-pose, NMS |
| `src/obs.rs` | клиент obs-websocket v5 (блокирующий, сокет на поток) |
| `src/engine.rs` | потоки рендера, распознавания и событий OBS; режимы сцен, выбор спикера, монтаж |
| `src/appearance.rs` | «отпечаток» одежды спикера |
| `src/watchdog.rs` | сторож камеры |
| `src/lower_third.rs` | плашка с именем (страница и шрифты встроены в exe) |
| `src/settings.rs` | настройки (совместимы с Python-версией) |
| `src/demo.rs` | демо-режим: картинка вместо OBS |
| `src/ui.rs`, `ui/app.slint` | окно: превью, настройки, подключение |

Отличие от Python-версии: свой цвет плашки задаётся полем `#rrggbb` (в Slint нет системного окна выбора цвета).
